# Cybersecurity Login Analyzer

## Project Overview

The Cybersecurity Login Analyzer is a beginner Python cybersecurity project that analyzes login attempts and identifies potentially suspicious activity.

The purpose of this project is to practice using Python while learning how login activity can be monitored for possible security threats.

## Features

- Analyzes user login attempts
- Identifies successful and failed logins
- Counts failed login attempts
- Flags users with multiple failed login attempts
- Displays security alerts for suspicious activity

## Technologies Used

- Python
- GitHub
- Cybersecurity concepts
- Data analysis

## Cybersecurity Concepts

This project demonstrates several basic cybersecurity concepts, including:

- Authentication monitoring
- Failed login detection
- Brute-force attack awareness
- Security logging
- Suspicious activity detection

## Project Files

- `login_analyzer.py` — Python program used to analyze login activity
- `login_attempts.txt` — Sample login data used by the program
- `README.md` — Documentation explaining the project

## What I Learned

Through this project, I practiced using Python to analyze security-related data. I also learned how failed login attempts can be monitored to help identify suspicious activity and possible unauthorized access attempts.

The program successfully identifies repeated failed login attempts and flags suspicious activity that may indicate a brute-force attack.
